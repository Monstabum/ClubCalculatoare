INSTRUCȚIUNI — AppClubCalculatoare (WinForms, .NET 8)
============================================================

1) BAZA DE DATE — varianta rapidă (recomandat):
   Dublu-click pe BD\Instaleaza_BD.bat (din folderul BD).
   Rulează singur, fără întrebări: dacă baza de date lipsește,
   o instalează complet (toate cele 8 scripturi); dacă există,
   face actualizarea sigură, fără pierderi (păstrează datele
   și pozele). Necesită sqlcmd (vine cu SQL Server). Serverul
   implicit este .\SQLEXPRESS; alt server: Instaleaza_BD.bat
   NUME_SERVER; reinstalare completă (resetează datele demo):
   Instaleaza_BD.bat NOU. Log tehnic: BD\bd_log.txt.

   Varianta manuală (SSMS, în această ordine):
   1. BD\ClubCalculatoare.sql
   2. BD\AuditLog.sql            (creează AuditLog + coloana email)
   3. BD\Autentificare_Update.sql (INSERT folosește coloana email,
      deci email trebuie să existe deja — vezi pasul 2)
   4. BD\Permisiuni.sql          (tabele Permisiuni/UtilizatoriPermisiuni,
      coloanele tentative_esuate/blocat_pana_la, view-urile
      vw_SesiuniComplete și vw_EchipamenteDisponibile)
   5. BD\MigrareFoto.sql         (tabela EchipamentFoto + indexuri +
      permisiunile FOTO_VIZUALIZARE_ECHIPAMENTE/FOTO_MODIFICARE_ECHIPAMENTE)
   6. BD\Favorite.sql            (tabela Favorite + permisiunea FAVORITE)
   7. BD\CalculatorCost.sql      (permisiunea CALCULATOR_COST)
   8. BD\Adauga_DurataMinute.sql (coloana Sesiuni.durata_minute)
   Toate scripturile sunt idempotente (re-rulabile).

2) CONNECTION STRING (AppClubCalculatoare\App.config):
   - Implicit: Data Source=.\SQLEXPRESS  (SQL Server Express).
   - Alternativ (comentată în fișier): Data Source=.  (SQL Server
     standard/Developer, instanța implicită).
   Decomentează varianta potrivită instalării tale.

3) SMTP (resetare parolă): completează în App.config, <appSettings>:
   SmtpHost, SmtpPort, SmtpUser, SmtpPassword, SmtpFrom.
   Fără ele, resetarea afișează „SMTP neconfigurat" și NU schimbă parola.

4) POZE DEMO (opțional): rulează Instrumente\gen_poze_demo.py (necesită
   Pillow: pip install pillow) pentru a regenera imaginile din PozeDemo\.
   La compilare, pozele sunt copiate automat lângă executabil.

5) CURĂȚARE + COMPILARE:
   - Închide Visual Studio.
   - Șterge folderele: AppClubCalculatoare\bin\, AppClubCalculatoare\obj\, .vs\
   - Deschide AppClubCalculatoare.sln(x), apoi Build → Rebuild Solution.
   - Țintă: C# 7.3, fără erori/avertismente CS0xxx.
